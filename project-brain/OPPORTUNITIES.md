# Money-Making Opportunity Database

_Last updated: 2026-09-25_

No individual live opportunity is seeded here yet because this Project Brain creation session did not perform a fresh opportunity search.

That is intentional: **do not fabricate current opportunities or treat old listings as live.**

The structured Opportunities register tracks:

- organisation
- problem
- category
- reward
- deadline
- requirements
- eligibility
- competition level
- estimated difficulty
- capabilities required
- tools required
- expected effort
- status
- source
- submission route
- result
- last checked
- confidence

## Candidate source categories

- paid GitHub issues
- software/open-source bounties
- legitimate authorised bug bounties
- smart-contract competitions
- data-analysis and optimisation competitions
- mathematical/scientific challenges
- forecasting tournaments
- engineering/research prizes
- specialised technical freelance work
- neglected commercial problems with strong demand/supply imbalance

## Accounting rule

DISCOVERED ≠ QUALIFIED ≠ SOLVING ≠ SUBMITTED ≠ ACCEPTED ≠ PAYOUT VERIFIED.
