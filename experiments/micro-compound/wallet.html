Device-only Solana key vault

Experimental key generator, not an audited spending wallet. Nothing is sent to a server. It does not connect to Micro Compound, hold a real deposit for the experiment, sign transactions or pay network fees. Do not fund a key created with this experimental tool. Existing Cobo Agentic Wallet accounts can be inspected separately through the owner's established Cobo pairing and permission policy.

When you choose Generate, your browser creates a new Ed25519 keypair locally. The private key is encrypted using a password you enter and saved in a downloadable encrypted JSON backup. Neither the password nor the private key is shared with ChatGPT or GitHub.



Public address

The address is public. The encrypted JSON backup contains the private key: store it securely offline and do not share it. Losing your password or encrypted backup can make the key unusable.
