# Third-party code

No source code copied from jev-trader, QuantDinger, NautilusTrader, Freqtrade or Cabbage in this prototype. Architectural concepts only. No runtime third-party Python dependencies.

Market sampling refers to Binance public market endpoints and DEX Screener publicly documented HTTP JSON APIs. Their availability and terms may change; no affiliation or endorsement is claimed. GitHub workflows invoke GitHub-maintained actions under their own licences.
